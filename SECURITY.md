# Security policy

This offline teaching tool does not execute evidence content. Parsers are intentionally narrow and use in-memory data structures; do not treat them as a hardened service for hostile or large files. Trusted repository manifests are not signed proof of authenticity.

For a security issue, use GitHub private vulnerability reporting if available. Otherwise open a minimal issue requesting a private reporting channel without publishing exploit details or sensitive data. No private endpoint or response-time guarantee is configured.

Version 0.1.x is experimental; fixes are best effort. Real forensic work requires an independently reviewed acquisition and analysis process.
